## 3. Architecture context

When you apply `ModelArtifact/gemma-2b-it` in `ai-serving`, `ModelArtifactReconciler` (`internal/controller/modelartifact_controller.go`):
1. Validates `spec.storageUri` is `@sha256:` pinned and `spec.modelFormat` is allowed.
2. Calls `registry.ResolveModelPackage` to fetch the OCI model manifest descriptors, `bundle-manifest.json` config blob, and the 4 OCI v1.1 Referrer blobs (`oms.sig.json`, `bom.cdx.json`, `evaluation.dsse.json` + `report.json`, `release-qualification.dsse.json`).
3. Executes the 7-step `pkg/verify` cryptographic pipeline and 9-rule policy evaluation (`internal/policy/evaluator.go`).
4. Updates `status.phase: Verified` and records `status.evaluatedPolicyDigest`, `status.policyGeneration`, and `status.validUntil`.

## 5. Step-by-step instructions

1. Apply `/tmp/model-work/modelartifact.yaml` to the `ai-serving` namespace.
2. Wait for `ModelArtifact/gemma-2b-it` to reach `status.phase == Verified`.
3. Inspect the complete cryptographic verification summary recorded in `status`.

---

## 6. Commands

```bash
# 1. Apply the ModelArtifact resource
kubectl apply -f /tmp/model-work/modelartifact.yaml

# 2. Check status table
kubectl get modelartifact gemma-2b-it -n ai-serving

# 3. Inspect detailed cryptographic verification status
kubectl get modelartifact gemma-2b-it -n ai-serving -o jsonpath='{.status}' | jq .
```

## 8. How to verify success

Confirm `status.phase` is `Verified` and `status.conditions[0].status` is `True`:

```bash
kubectl wait --for=jsonpath='{.status.phase}'=Verified modelartifact/gemma-2b-it -n ai-serving --timeout=30s
```

## 9. Common errors

| Error | Cause | Fix |
|---|---|---|
| `OCI_RESOLUTION_FAILED` | Controller ServiceAccount lacks `roles/artifactregistry.reader` or wrong digest in `storageUri` | Verify Workload Identity annotation on `ServiceAccount/model-admission-controller` and check `storageUri` |
| `BUNDLE_ID_MISMATCH` | `spec.bundleIdentity` does not match the pushed OCI layers | Copy the exact `Bundle Identity` printed by `modelctl push` |

## 10. Security considerations

- **Zero Weight Download**: Notice that reconciliation completed in `< 300 ms`—the controller verified all 6 model layer descriptors (`config.json`, `model.safetensors`, `tokenizer.json`, etc.) without downloading `.safetensors` weights into the controller pod.
